# CS-744-Design-and-Engineering-of-Computing-Systems
## This Repository Contains all my Assignments @ IITB Fall Semester 2022.

_Abstract: This project presents the design, implementation and evaluation of a robust, multi-threaded web server using a master–worker thread-pool architecture, engineered to process HTTP requests and generate responses while minimizing latency and maximizing concurrent resource utilization. A closed-loop load generator measured average throughput and response times across varying concurrent user loads; system reliability and memory management were validated using Valgrind to ensure the absence of memory leaks and maintain stability under high stress. Subsequent analysis of load-testing data identified critical resource bottlenecks, driving targeted optimizations that significantly improved overall system efficiency and scalability._
